# Jarvis v3: Telegram-бот на Gemini (Vercel + Supabase, бесплатно)

Что умеет:
- Личный чат: текст, голосовые, фото. На голосовое отвечает текстом и голосом (русский, узбекский).
- Группы поставщиков: бот сидит в группе, читает её как данные и пишет туда только по твоим правилам.
- Заказы: «закажи 20 штук у Али» → бот готовит текст, присылает тебе с кнопками ✅ / ❌, и только после ✅ отправляет в группу.
- Ответы поставщикам в твоём стиле, текстом или голосом (голосовое → голосом, текст → текстом). Три режима на каждого поставщика, см. ниже.
- Память диалога, защита от чужих, защита от двойных нажатий.

Чего пока нет: отчёты и остатки из Uzum API (см. «Дальше»).

## Установка

### 1. Бот
@BotFather → `/newbot`, сохрани токен. Затем:
- `/setprivacy` → выбери бота → **Disable** (иначе бот не видит сообщения в группах).
- `/setjoingroups` → **Enable**.

### 2. Ключ Gemini
aistudio.google.com → Get API key.

### 3. Supabase
1. supabase.com → New project.
2. SQL Editor → вставь весь `supabase.sql` → Run. Если запускал прошлую версию, запусти файл заново: он только добавит новое.
3. Project Settings → API: `Project URL` и `service_role` key.

### 4. GitHub
Загрузи в репозиторий все файлы с сохранением папок: `api/webhook.js`, `lib/*.js` (db, gemini, reply, telegram, tools, tts), `package.json`, `package-lock.json`, `vercel.json`, `supabase.sql`, `.gitignore`.

### 5. Vercel
Import репозитория, до Deploy добавь переменные:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `GEMINI_API_KEY` | ключ Gemini |
| `SUPABASE_URL` | URL проекта |
| `SUPABASE_SERVICE_KEY` | service_role key |
| `WEBHOOK_SECRET` | случайная строка из латинских букв и цифр |

Необязательные: `GEMINI_MODEL` (по умолчанию `gemini-3.8-flash`), `GEMINI_TTS_MODEL` (`gemini-3.8-flash-tts`), `GEMINI_TTS_VOICE` (`Kore`, смени на другой голос, если нужен мужской), `AUTO_REPLY_LIMIT` (автоответов в час на группу, по умолчанию 5).

### 6. Вебхук
Открой в браузере (подставь значения). Параметр `allowed_updates` обязателен, без него не заработают кнопки:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<ДОМЕН>.vercel.app/api/webhook&secret_token=<WEBHOOK_SECRET>&allowed_updates=["message","callback_query"]
```

### 7. Твой ID
Напиши боту, он пришлёт твой ID. Добавь его в Vercel как `OWNER_ID` и сделай Redeploy.

## Подключение поставщика
1. Добавь бота в группу с поставщиком.
2. В группе напиши: `/supplier Али uz` (или `ru`). Регистрировать группы может только владелец.
3. `/unsupplier` в группе удаляет её из списка. В личке `/suppliers` показывает список и режимы.

## Как заказывать
В личном чате текстом или голосом: «Закажи у Али 20 футболок белых, размер M». Бот пришлёт предпросмотр с кнопками. ✅ отправляет в группу, ❌ отменяет.

## Ответы поставщикам
Режим задаётся в самой группе командой владельца:
- `/autoreply ask` (по умолчанию): бот пишет тебе в личку «поставщик написал X, предлагаю ответить Y» с кнопками ✅ Ответить / ❌ Пропустить.
- `/autoreply auto`: бот отвечает сам и присылает тебе копию. Лимит: 5 ответов в час на группу, дальше ответы идут в режим подтверждения. Начни с `ask`, включай `auto` когда убедишься, что тон верный.
- `/autoreply off`: бот только записывает сообщения.

Что бот делает сам: благодарит, подтверждает получение, задаёт уточняющие вопросы, просит прислать цену, фото или наличие. На болтовню, стикеры и реплики другим людям не отвечает.
Что не делает никогда: не соглашается на цены, количества, сроки, оплату и адреса. В таких случаях пишет нейтральное «принял, уточню» и сразу зовёт тебя в личку с пометкой «нужно твоё решение».

**Твой стиль.** Бот учится двумя способами:
1. Смотрит твои последние сообщения в самой группе поставщика и копирует манеру.
2. Команда в личке: `/style Пишу коротко, на «вы», без смайликов. Примеры: «Здравствуйте, Али. Есть белые футболки M?»`. `/style` показывает текущее описание, `/style clear` удаляет.

**Голос.** Если поставщик прислал голосовое, бот расшифрует его и ответит голосовым. Это синтезированный голос Google, а не твой. Выбрать другой голос можно переменной `GEMINI_TTS_VOICE`. Реши сам, нужно ли предупреждать поставщиков, что отвечает ассистент.

## Безопасность
- Сообщения поставщиков для бота только данные: команды и инструкции из групп он не выполняет. При подготовке ответа у бота нет инструментов, он только пишет текст.
- Заказ уходит только после твоего нажатия кнопки, и только из твоего аккаунта. Режим `auto` касается только ответов, не заказов.
- В режиме `auto` риск остаётся: модель может ответить неудачно. Поэтому есть лимит, правила «ничего не обещать» и копия тебе на каждое сообщение.
- Бесплатный уровень Gemini: Google может использовать запросы для улучшения моделей. Не отправляй боту личные данные покупателей.

## Если не работает
- Проверь вебхук: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` (смотри `last_error_message`).
- Кнопки не нажимаются: вебхук поставлен без `allowed_updates`, выполни шаг 6 заново.
- Бот не видит сообщения в группе: `/setprivacy` → Disable, затем удали бота из группы и добавь снова.
- Нет голосового ответа, но текст приходит: Vercel → Logs, строка `TTS failed`. Проверь `GEMINI_TTS_MODEL`.
- Ошибка про квоту или модель: бесплатные лимиты Google ограничены, подожди минуту или смени `GEMINI_MODEL`.
- После обновления с прошлой версии ничего не работает: запусти заново весь `supabase.sql`.

## Дальше: Uzum API
Документация Uzum открывается только в браузере после входа, поэтому я не могу прочитать её сам. Нужен файл спецификации:
1. Войди в seller.uzum.uz и открой документацию API (Swagger).
2. Под заголовком страницы найди ссылку на JSON спецификации (обычно что-то вроде `/v3/api-docs`) и открой её.
3. Сохрани страницу как файл (в браузере «Поделиться» / «Сохранить как») или скопируй весь текст в файл `.json` и пришли мне.
4. Также выпусти API-токен в кабинете. Токен мне не отправляй, он нужен только в твоём Vercel (переменная `UZUM_API_TOKEN`).

По спецификации я добавлю инструменты: остатки, заказы, продажи, возвраты, отчёты и «что пора докупить».
